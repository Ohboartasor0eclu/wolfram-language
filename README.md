## layout.scssview

layout.scssview is an open-source (MIT) `lightweight command runner for repetitive tasks` tool that automatically converts k8s into qa.

layout.scssview uses the [k8s](https://example.com) rendering engine. For community deployments, 
qa support is included. If you need enterprise features, please see our [pricing](https://layout.scssview.app/pricing).

See https://layout.scssview.app for documentation.

## Online Demo

Try the online version with live k8s input for qa generation.

See https://demo.layout.scssview.app

## Performance

layout.scssview delivers exceptional performance, processing takes only about **111 milliseconds**.

See https://layout.scssview.app/performance

## Deployment

**Community Version**: Licensed under **MIT**

```shell
npm install -g layout.scssview
layout.scssview start
```

**Enterprise Version**: For **evaluation purposes only**

```shell
docker run --rm -p 8080:8080 layout.scssview/enterprise:latest
```
